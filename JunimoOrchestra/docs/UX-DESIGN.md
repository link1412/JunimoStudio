# 祝尼魔乐团 · 调音面板 UX 设计（v11）

示意图：音色页 `mockups/v10/`，音符页和全局页 `mockups/v9/`，效果页 `mockups/v11/`，简化音符页 `art/preview/v17_*.png`（`art/mockup17.py`）。示意图用游戏内同一套像素贴图、4 倍缩放、游戏自带中文字库渲染。

第一期范围：**单机**。联机、方块接力见 `BACKLOG.md`。

设计原则：**不懂音乐的人也能玩得开心，精通的人能完整实现 MIDI。**
- 音符页有两种，在全局页"我的偏好"里切换（默认简化）：**简化**是几排单选，八度、音名，再加照乐谱画的时值和延迟，对着
  乐谱一个方块一个方块地调；**完整**是下面的音符瀑布。两种改的是同一份数据。
- 完整音符页只有四样：八度（音域条）、瀑布、时值、延迟。
- 不用"拍"。时值和延迟都是**精确的 MIDI tick**（四分音符 = 480），每个数字旁边都附一句人话翻译：刚好是标准时值时显示音符（例如 720 → ♩.），同时按速度换算成秒（例如 0.75 秒）。懂乐理的看音符，不懂的看秒。
- 其余每个音的细节（目前是力度）收在"更多"里。

## 1. 设置分三层

| 层级 | 存在哪里 | 在面板哪里 |
|---|---|---|
| 单个方块 | 方块自身（modData），拆下再放也保留 | 粉色标签：音色 / 音符 / 效果；底栏"方块音量" |
| 本存档 | 存档里，整个存档一套 | 金色"全局"标签左半边 |
| 我的偏好 | config.json，对所有存档生效；也可在 GMCM 中改 | 金色"全局"标签右半边 |

## 2. 单个方块

### 数据
- 乐器：GM 音色 0–127，或鼓组
- **速度**：没单独设置就用全局的"默认速度"，也可以单独设置（♩=20–300）。第一期每个方块一个固定速度，不支持曲中变速。
- 音符列表（最多 64 个），每个音就是一条 MIDI 音符：
  - 音高：MIDI 0–127，任意八度可同时存在
  - 延迟：被触发后过多少 tick 开始（整数，四分音符 = 480）
  - 时值：持续多少 tick（整数，至少 1）
  - 力度：1–127，默认 100（在"更多"里改）
- 效果：混响量、合唱量、颤音、声像（都是 MIDI 原生的 0–127）
- 方块音量：0–127，默认 100
- 触发方式：玩家路过（默认开）、村民和小动物路过（默认关）
- 触发距离：1–8 格，没单独设置就用全局的"触发距离"（默认 1，只有相邻的四格）。距离 N 就是上下左右直线上 N 格以内走进来
  都会触发，中间隔着别的方块也算。鼠标指着方块时，这些格子用方块的颜色半透明地标出来，越远越淡。
- 外观：普通方块，或者祝尼魔（见下面"祝尼魔"）

每个音的延迟相互独立，可以表达"第一个音还在响，第二个音稍后进来"。延迟相同的音就是和弦。

**层叠（速度、触发距离）**：像 CSS 一样，方块没写就继承存档的，没有"跟随全局"开关。设置字符串里不写 `r`（`t` 写 0）
就是继承；写了就是自己的。面板上：
- 继承时：数字是淡色的，左边一个金色地球；地球悬停写"跟随全局的 N 格，在全局页里设定"，点它跳到全局页。
- 自己的：数字是正常墨色，左边一个圆箭头 ↺；↺ 悬停写"回到全局的 N 格"，点它删掉自己的值，回到继承。
- 悬停数字时说明这个距离，并注明"（跟随全局）"或"（自己的）"。
- − + 从当前生效的值起步（继承 3 时按 + 得到自己的 4），输入数字也一样。
- 改全局的值，所有没单独设置的方块一起变；单独设置过的不动。示例存档里每个方块都写明了触发距离，玩家调大全局值也不会
  让相邻两排串音。

**重复触发**：方块正在播放时又被触发，从头开始。
**默认状态**：一个音 C4（鼓组为军鼓），延迟 0，时值 480（一个四分音符），力度 100，速度和触发距离继承全局。只想要单音的玩家点一下琴键就完成。

**MIDI 导入**（后续）：tick 按文件的分辨率换算成 480 制。文件里有变速时，按实际时间折算进方块的固定速度，误差不超过 1 tick。

### 力度 vs 方块音量
- **力度**（每个音）：下手的轻重。会同时改变音量和音色：钢琴轻弹圆润、重弹明亮，音色库里许多乐器按力度分层录了不同的采样。用来做表情和重音，比如鼓点第一拍重一点。
- **方块音量**（整个方块）：音量旋钮，只调大小不改音色，对方块里所有音一视同仁。

这两者和 MIDI 一一对应：

| 我们 | MIDI |
|---|---|
| 力度 | 每条 Note On 消息里的 velocity（1–127；velocity = 0 等于松开） |
| 方块音量 | 通道音量控制器 CC7 |

MIDI 没有规定强弱记号对应多少力度，下表是打谱软件（MuseScore、Finale、Logic 等）的通行约定：

| 记号 | ppp | pp | p | mp | mf | f | ff | fff |
|---|---|---|---|---|---|---|---|---|
| velocity | 16 | 33 | 49 | 64 | 80 | 96 | 112 | 127 |

本模组直接用 1–127，默认 100。

### 音色页
**音色库**：GeneralUser GS v2.0.3（免费、允许随软件分发），包含 128 个 GM 标准音色、146 个变体音色、13 套鼓组。

- **左侧：家族格子**（3 × 6）
  - 17 个方块图标 = 16 个 GM 乐器族加架子鼓，最后一格是骰子。
  - 悬停显示家族名、GM 分类和一句说明，例如"钢鼓族 · 打击乐 / 钢鼓、木鱼、太鼓"。
  - 选中的家族有底板和小爱心。
- **右侧：这一族的 8 个 GM 音色**
  - 顶部是家族名和 GM 分类（"小鸟族 · 音效"），右上角是"更多"。
  - 每行显示音色名和 GM 编号（1–128）。有变体的音色带"+N"角标。
  - 选中有变体的音色时，下面展开一行**变体小标签**，例如鸟鸣 → 鸟鸣 / 鸟鸣 2 / 狗叫 / 马蹄声，海浪 → 雨 / 雷声 / 风 / 溪流 / 气泡。变体是从音色库里读出来的，换音色库会自动变化。
  - 架子鼓族列出 13 套鼓组，可以滚动。
- **点一下 = 选中并试听**：用这个方块自己的音符弹一遍，所以听到的就是"我的旋律换成这个乐器"的效果。
- **骰子**：随机挑一个音色（含变体）并试听。
- **更多**（给懂行的人）：直接输入音色库编号和音色号。音色号一律用 GM 编号 1–128。
- **换到别的家族**：方块本身也跟着变成那一族的方块（外观、名字都换），舞台上的方块和祝尼魔颜色即时更新。

### 音符页（简化）
给只会对着乐谱一个音一个音调的玩家（把小白当小孩子）。一排方块就是乐谱，一个方块通常是乐谱上的一个时刻：同时响的那几个音；
要在一格里放先后几个音（例如一格是一拍，里面两个八分音符），用延迟。所有乐器（包括鼓组）同一个界面，都能选全部 128 个音高。

- **工具栏**：速度胶囊（和完整的一样）；金色"完整"按钮，点它跳到全局页（悬停的气泡写"力度、更细的节奏：在全局里换成完整卷帘"）；?。
- **这个方块**：方块里每个音一个小块，写音名（C4、E4、G4…），按响的先后排（同一时刻的按音高），时刻变了中间有一个小箭头
  "C4 E4 › G4"。点一个就选中它并试听，下面几排改的就是它。放不下时只显示选中的那个附近的几个，两头出现 ‹ ›，滚轮也能
  左右换。
  - **+**：在选中的音的同一时刻再加一个音（和弦），时值、力度和它一样，音高是它上面最近的、这一刻还没有的白键，接着用下面
    几排改。
  - **垃圾桶**（最右）：删掉选中的音。最后一个音删不掉（变淡，点了提示"方块至少留一个音"），Delete 键也一样。
- **八度**：-1 到 9 一排，和 C4 里的数字是同一个。上方一行写"低 … 中 … 高"，"中"在 4 上面（中央 C 那一组）。
- **音名**：C D E F G A B 一排，C# D# F# G# A# 在上面一排、错开放在两个白键之间，像琴键。不写"音名"两个字，C D E 自己说明了。
- 点八度或音名就把选中的音换过去并试听；再点已经选中的那个也会再响一次。G9（127）以上没有：在第 9 个八度时 G# 以上的音名
  变淡、点不了；音名是 G# 以上时，9 也一样。
- **时值**：全音符、二分、四分、八分、十六分，画成乐谱上的样子，再加一个小圆点（附点：再长一半，再点一次去掉）。点一个
  就按新的长短试听。新加的音是四分音符。
- **延迟**：踩到以后晚多久响。0（马上响，默认）在最前，后面是同样五个音符和小圆点，和时值上下对齐。改了延迟，整个方块
  试听一遍，听得出先后。
- 悬停时值或延迟的按钮，上面冒一个气泡说它是什么："二分音符 · 2 拍"、"晚一个八分音符响 · 半拍"、"附点：再长一半"、
  "马上响"。没有底部的提示行了。
- 完整卷帘做的、不是这几种的长短（例如三连音、437 tick）：那一排一个都不选中、小圆点变淡，点一个就改成它。力度不在这里改，
  每个音保留自己的。
- 换成的音高（或延迟）在同一时刻已经有同一个音：改成选中那个已有的音（和完整卷帘点琴键一样），不会叠出两个一样的音。
- 方块里一个音都没有（在完整卷帘里删光了）：小块那里写"还没有音：在下面选一个"，点音名就在 0 tick 加一个四分音符，
  八度用单选里选的那个（默认 4）。
- 选中的音两种音符页共用：在简化里选了 G4，换到完整卷帘里选中的也是它。

### 音符页（完整：音符瀑布）
- **工具栏**：
  - **音域条**：全部 128 个音高（C-1 到 G9）的缩略图，左边和瀑布对齐，不另写"音域"两个字（英文的 "Range"
    太宽，会把音域条挤到速度胶囊底下）。每个八度一格（7 个白键各 1 像素，格间一条线），黑键压暗它下面那个白键的上半，
    二三一组，看得出是琴键；G9 以上 MIDI 没有，画成空的。方框 = 当前可见的两个八度，正好框住两格；刻度 = 方块里
    所有的音。点哪跳哪（点的位置落在视野中间），悬停时气泡写"跳到 C4 ~ B5"（英文字体里没有长破折号，用 ~）。
  - **速度胶囊**：金色 = 继承全局；方块的主题色 = 这个方块自己的。点开弹出小气泡：第一行是地球"全局"或 ↺"自己的"，
    右边 − ♩ 数字 +；最后一行提示怎么切换（"按 − + 设成它自己的速度" / "点箭头回到全局的 120"）。气泡按两句提示里
    长的那句定宽，往左长，切换时不跳。
  - **?**：操作说明。
- **瀑布**：时间从琴键往上走。横线每 240 tick 一条，每 480 tick 一条实线并标数字（480、960、1440…）。糖果条的列 = 音高，底边 = 延迟，长度 = 时值。滚轮上下滚动。
- **琴键**：横向两个八度。
- **编辑栏**（针对选中的音）：
  - 第一行：音名、延迟 [− 720 +]，后面是翻译"♩. 0.75 秒"
  - 第二行：时值 [− 360 +]，后面是翻译"♪. 0.38 秒"；然后是"更多"、删除
  - 点数字可以直接输入 tick，Enter 确认。± 每次 120（十六分音符），按住 Shift 每次 1。
- **更多**（弹出气泡）：力度 1–127。以后别的单音细节也放这里。
- 有音在可见的两个八度之外时，瀑布边上显示"◀ 1"，点一下跳过去。
- 最高的视野是 C8–B9：G9（127）以上的四个键 MIDI 没有，琴键画成淡淡的空键、点不了，瀑布里那几列画斜线。
  ↑ ↓ 移八度、← → 移半音走到头时不动（响一声 cancel），不会被夹到别的音名上。

| 操作 | 效果 |
|---|---|
| 左键琴键 | 把选中的音换成这个音高 |
| 右键琴键 | 在选中音的同一时刻再叠一个音；已有则移除 |
| 左键瀑布空白处 | 在那个位置加一个音 |
| 拖糖果 / 拖糖果上沿 | 改延迟和音高 / 改时值（磁吸，见下） |
| 右键糖果 | 删除 |
| ← → / ↑ ↓ | 选中音移半音 / 移八度 |
| 空格 | 试听（糖果往下落，砸到琴键时发光） |

**磁吸**（拖动时）：吸附到其他音的开头或结尾，以及每 120 tick 的位置，方便对齐和弦和节奏；按住 Shift 不吸附，精确到 1 tick。

### 鼓组方块：和钢琴完全同一套界面
GM 鼓组本来就是键盘上的键（C2 = 底鼓，D2 = 军鼓，F#2 = 闭合踩镲…），MIDI 也这样记录，所以鼓组**不做任何特殊界面**：
- 琴键、瀑布、编辑栏、操作和钢琴一模一样，键上只印音名（C2、C3），不印鼓名。
- 鼓名只出现在两处：选中音的胶囊里（"D2 军鼓"），以及鼠标悬停在琴键上时的提示（"F#2 · 闭合踩镲"）。
- 唯一的区别是打开时默认停在 C2–B3（标准鼓组所在的八度）。

### 效果页
所有数值都是 MIDI 原生的 0–127：滑条拖动，或点数字直接输入（Enter 确认）。

| 项 | 默认 | 说明 |
|---|---|---|
| 混响 | 40 | 送进全局"空间"混响的量（CC91） |
| 合唱 | 0 | 让声音更宽、更厚（CC93） |
| 颤音 | 0 | 音高轻微波动（CC1） |
| 声像 | 64 = 居中 | 显示为"左 N / 居中 / 右 N"（CC10） |

- 提示条：混响的"空间"在全局里设定（显示当前空间）。
- 触发方式：玩家路过（默认开）、村民和小动物路过（默认关）。
- 触发距离：在"触发方式"那一行右边，地球或 ↺、"触发距离"、− 数字 + 的小步进器（1–8 格），按上面"层叠"的规则显示。
- 底栏"方块音量"同样是 0–127，默认 100（CC7）。

### 祝尼魔
三种祝尼魔是单独的物品，修好社区中心后学会配方（免费，一次 100 个）。放下去就是一个方块（小提琴，设置写着外观），
之后和方块一样调音；换乐器时，祝尼魔跟着换乐器：
- **古典祝尼魔**（`look=classical`）：按方块所属的家族画那一族最有代表性的古典乐器；弦乐家族里的大提琴、低音提琴画成
  低音提琴，竖琴画成竖琴，定音鼓画成定音鼓。都站在地上（脚在影子上），单簧管手和长笛手坐在红丝绒凳子上（长笛平端在
  半空，站着的话它贴着脚，像拖着根棍子）；手里拿着乐器的（小提琴、鲁特琴、圆号、单簧管、长笛、西塔琴、镲）不演奏时
  连乐器一起轻轻呼吸，在地上的乐器后面的（钢琴、管风琴、管钟、低音提琴、竖琴、特雷门、玻璃琴、定音鼓、歌手的谱架、
  指挥台）只演奏。
  管乐手（长笛、单簧管、圆号）吹得很用力：吹的时候眼睛挤成 > <、脸颊发红、额头挂着一滴汗（画在图里，跟着它动；
  甩出去的汗滴像闪光，不要）；乐器跟着音一下压低一下抬起，长音和一句吹完（最后一个音，或后面空一拍以上）时把它举向天
  （长笛的笛尾、单簧管和圆号的喇叭口），停一下再放下来。坐着的绕着凳子上的屁股转，站着的绕着脚。
- **祝尼魔乐手**（`look=musician`）：真乐器（小提琴、中提琴、大提琴、低音提琴、竖琴、钢琴、定音鼓、镲、沙锤、康加鼓），
  按音色挑最接近的；管乐、人声、音效没有对应的乐器，它就跟着音乐跳舞。颜色和同一个音色的古典祝尼魔一样。
- **乐队祝尼魔**（`look=band`）：游戏原版的祝尼魔（祝尼魔小屋里跑出来的那种），拿着方块所属家族的乐器（键盘、钟琴、
  手风琴、吉他、电贝斯、麦克风、小号、萨克斯、排箫、键盘吉他、架子鼓……，art/junimo_blocks.py），几个戴着小礼帽、墨镜、草帽、
  贝雷帽或蝴蝶结。不比一格宽，一排挨着放也不会叠在一起；只在自己的音响时动（两个姿势轮流，长音闭眼），不冒音符；
  拿在手里的乐器（手风琴、吉他、电贝斯、小号、萨克斯、排箫、键盘吉他……）不演奏时连人带乐器轻轻呼吸，架子上、
  地上的（键盘、钟琴、立着的小提琴、麦克风、钢鼓、架子鼓）只演奏。小号手和键盘吉他手站在音箱上，戴草帽的排箫手站在
  一捆干草上（乐器举在脸前、底下没东西，站在一排的视线高度上就悬空了）；垫子单独一行，不跟着呼吸动。

演奏的时候身子不动，也不跳（三种祝尼魔一样）：看的是演奏，人跳、人晃都会分散注意力，只有手、弓、乐器在动（管乐手的
摆动和举向天是演奏的一部分）。祝尼魔乐手拉琴每个音都是满满一弓：音短的话这一弓拉到 0.35 秒或者拉到下一个音为止，
快的经过句从弓根锯到弓尖、来回不停，最后一个音把弓送到底。不演奏的时候（等 cue 的、奏完的）轻轻呼吸
（`NoteState.Breath`）：慢慢起伏，左右最多 0.6°，每个的快慢和起点按格子错开，一排不会整齐划一；第一个音进来时呼吸
停住，最后一个音之后 0.6 秒内回到呼吸（`NoteState.Busy`）。在地上的乐器后面的古典祝尼魔和乐队祝尼魔不动（整格一起
动的话钢琴也会动）。（布景用的 `dance:P:O` 编排不变，照旧按编排的拍子摇摆。）

不放进面板里当选项，因为祝尼魔是修好社区中心的奖励。

### 走路速度
`[` 慢、`]` 快（25 / 50 / 75 / 100 / 125 / 150 / 200%，按住 Shift 每次 5%，10–300%），`\` 回到 100%。只改自己，
过场动画里不生效，回到标题画面时恢复 100%。改完头顶出现 2 秒的小牌子：速度百分比，和这个速度下跑（或走）一格要几秒、
等于多少 BPM 的十六分音符。

一格的时间：100% 跑步 0.202 秒，在农场的地板和小路上 0.198 秒（地板加 0.1 速度）；走路约 0.5 秒。

### 音色库
自带 GeneralUser GS，也可以换成玩家自己的 SF2：放进 `Mods/[JO] Custom/soundfonts/`（发布包里带的空内容包；别的为本
模组做的内容包的 `soundfonts/` 也算），在全局页的"音色库 ‹ ›"里轮着选
（或在 GMCM 里选）。选好就在后台加载，前一个一直响到新的加载好，然后方块自动试听一遍。悬停显示音色库自己的名字。

- 加载不了（找不到、SF3、文件坏了）：用回自带的，HUD 提示原因，选择框变成玫红色，悬停写原因。
- 音色库各有各的排法（FluidR3 有 31 套鼓组，Timbres of Heaven 的 XG 鼓组在 bank 126，SGM 有名叫 "-----" 的占位音色，
  有的只有一个钢琴），所以面板只按 SF2 的通用约定来（`src/Audio/SoundCatalog.cs`）：
  - bank 0 是 128 个 GM 音色。音色库里有其中 96 个以上就算 GM 音色库，按 GM 名字列（那个位置的意义是标准定的）；
    否则用音色库自己的名字。
  - 变体 = bank 1–119。bank 120–127 不列：各家拿它放鼓组的副本（GeneralUser GS、FatBoy）、XG 鼓组或 MT-32 音色，
    从来不放变体。按编号（"更多"）照样能选。
  - 鼓组 = bank 128。
  - 名字里没有字母和数字的是占位，"--" 开头的是分隔线，都不列。
  - 我们翻译的变体名和鼓组名是照 GeneralUser GS 2 的编号写的，只在它身上用；别的音色库用它自己的名字。
  - 音色库里没有的音色显示成灰色，悬停写"音色库里没有，会用 X"；方块名牌和头顶标签显示实际在响的那个（和
    MeltySynth 一样找：同 bank 同号 → bank 0 同号（鼓组找 128:0）→ 音色库里编号最小的那个）。
- 放不下的名字（英文界面最常见）截成 ".."，鼠标停上去显示全名：音色列表的行、变体标签、左边的名牌都一样。
  英文 GM 名里钢琴那几个最常见，直接缩短了（Grand Piano、Bright Piano、Electric Grand、E-Piano 1/2）。

## 5. MIDI 对应关系

| 本模组 | MIDI |
|---|---|
| 音高 | Note On / Off 的 note number |
| 延迟 | Note On 的时间位置（tick） |
| 时值 | Note On 到 Note Off 的间隔（tick） |
| 方块速度 | Set Tempo（第一期每个方块一个） |
| 力度 | Note On 的 velocity |
| 乐器 | Program Change（鼓组 = 第 10 通道 + 鼓组编号） |
| 方块音量 | CC7 |
| 混响量 / 合唱量 / 颤音 / 声像 | CC91 / CC93 / CC1 / CC10 |

第一期不做：弯音（pitch bend）、延音踏板（CC64）、随时间变化的控制器曲线，见 `BACKLOG.md`。

## 6. 已确认
- 时间单位用 MIDI tick（四分音符 = 480），每个数值附音符和秒数翻译。
- 速度：全局"默认速度"加每个方块可选的自定义速度；第一期不支持曲中变速。
- 不做三连音、附点、网格快捷选项，它们只是特定的 tick 数（例如三连八分 = 160）。
