# Backlog — 后续版本

## 传递（方块接力） — 推迟到下一期

**目标**：方块被触发后，把演奏"接力"给相邻方块，玩家可以在地上搭出会自己演奏的音乐机器。

已确定的设计（来自 v2 示意图 `mockups/v2/4-联动.png`）：

- **方向**：上 / 下 / 左 / 右，四向可多选。面板里用"邻居小地图"呈现：中间是当前方块，四周显示实际摆放的相邻方块（空位显示虚线框），点箭头开关。
- **时机**：`立刻` 或 `乐句结束后`（默认），再加 `再多等 N 拍`。
- **时间基准**：全部对齐全局速度（BPM），以"拍"为单位，不按毫秒；接力链条在音频线程里按采样精度排程（lookahead scheduler），不受游戏掉帧影响。
- **循环**：首尾相连会循环演奏，这是特性。停止方式：全局页"停止所有演奏"、离开地点自动停止、可配置快捷键。
- **防爆炸**：同一方块被同一波次重复触发时合并；单个地点同时待触发事件上限（例如 256）。

实现时要回到面板加一个"联动"标签，或者在"效果"页的"触发方式"下扩展。

## 联机 — 推迟到后续

第一期只做单机。联机时需要：
- 全局设置（速度、摇摆、空间、移调）以房主为准并同步。
- 方块设置已存放在 modData（游戏自带同步），主要检查编辑冲突：两人同时打开同一方块的面板。
- 路过触发在各客户端本地判定（与原版长笛块一致）；面板试听等非路过触发通过 SMAPI 消息广播。

## 调音台界面 — 推迟到以后

**目标**：歌曲的混音在游戏里看得见、调得了，调好的设置和方块一样存进歌里。现在混音设置从文件载入
（`music/out/blocks/*.mix.json`，结构见 `music/engine/src/Mixing/MixSettings.cs`），只能改文件。

已定的：
- 模型里的每一项都要能在界面里调：通道的 EQ、宽度、声像、增益、按段落的推子和宽度、压缩、削波；总线的推子、分段 EQ、
  宽度、高通；母带的压缩、推子、削波、限幅、结尾淡出。效果和混响也要能拧。
- 按段落的设置跟着她在歌里的位置走（`SongClock`），所以界面里按段落编辑，不按秒。
- 数值不随她的速度变（2026-10-05 定）。
- 演奏中拧旋钮马上生效（2026-10-05 定）：第 f 帧拧的，从那一帧的第一个采样再过一个提前量（0.3 秒）起生效，那是
  还没渲染的最早一个采样，由帧决定；改动和触发记在同一份记录里，重放在同一个采样上生效，仍然逐字节一样。增益、EQ
  的变化在几毫秒里滑过去，不出拉链声（逐采样算，照样确定）。
- 混响用音源自带的，调音台上不另加（2026-10-05 定）：复古版就是忠实的 MU2000，它的混响是音色的一部分，也在参照母带
  master_v17 里。11 台的混响设置相同、混响是线性的，加起来就等于一路共用的混响。界面里每条通道给混响、合唱发送旋钮，
  再加全局的混响类型和时间；这些都是歌里的 MIDI 设置，两种音源都照着放，也自然进记录。等音源做不到的需求出现，再考虑
  调音台上的混响。
- 以后可以加"照计划放"：不用她走，方块按计划的帧触发（照样经过方块），坐着就能调混音。

## 音色库（SF2）的剩余部分

现在任何能读的 SF2 都能用（`[JO] Custom/soundfonts/`，见 UX-DESIGN 的"音色库"），还没做的：
- **宽松读取**：MeltySynth 发现任何一个采样的起止点、循环点越界就拒绝整个文件（FluidSynth 会修正后照样用）。本机的
  6 个音色库都能读；遇到坏文件现在是用回自带的并提示。以后可以在引擎里把越界的位置夹回范围、循环点不对就当不循环，
  好文件逐字节不变。
- **SF3**：要 Ogg Vorbis 解码（例如 NVorbis），载入时解成 16 位。
- **bank 120/126/127 的鼓组**：现在只列 bank 128。Timbres of Heaven 的 XG 音效鼓组在 126、SGM 有几套只在 120/127，
  只能按编号选，而且选了会当成旋律方块（默认八度、键上的鼓名不对，声音是对的）。
- 每个音色库的响度不同：可以加一个音色库增益（现在的 3 倍补偿是按 GeneralUser GS 定的）。
- 新放进文件夹的音色库，GMCM 的下拉要重启游戏才看得到（面板里马上就有）。

## 第一期已知限制（实测后记录）

- **手柄**：调音面板目前只支持鼠标 + 键盘，还没有手柄的方向键导航。
- **小窗口**：界面视口小于约 944×696（例如 1280×720 窗口 + 界面缩放 > 100%）时，面板整体按非整数比例缩小，像素会不均匀。以后可以做一套 3 倍的布局。
- **英文界面**：英文字体比中文宽。钢琴那几个最常见的名字缩短了（Grand Piano、E-Piano 1……）；其余放不下的音色名截成 ".."，鼠标停上去显示全名（列表行、变体标签、左边的名牌都是）。复制 / 粘贴放不下图标时只显示文字。
- **炸弹炸掉方块**：镐和斧头敲下来的方块会保留调子；炸弹走的是另一条代码路径，还没验证。
- **音色库重复的鼓组**：GeneralUser GS 在 bank 120 里复制了一份鼓组（给 GS/XG 文件用），面板里隐藏了；通过"更多"手动输入 bank 120 仍然能用。
