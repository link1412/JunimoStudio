# 示例存档

一个全新的标准农场，房子下面四排示例，每排一条小路，从左往右跑过去就是一段曲子；路口有牌子写着是什么（中英文跟着游戏语言）。
房子门口有一箱方块（每种 100 个，两种祝尼魔各 20 个）可以拿来试。

| 行 | 曲子 | 外观 | 摆法 |
|---|---|---|---|
| 19 | 贝多芬《致爱丽丝》开头 | 普通方块 | 两只手合在一排钢琴方块里，一格一个十六分音符 |
| 23 | 同上 | 普通方块 | 一只手一排（上八音盒、下竖琴），一个方块一小节 |
| 35 | 德彪西《第一阿拉伯风格曲》1–5 小节 + E 大三和弦 | 古典祝尼魔 | 上竖琴、下钢琴，一个方块一拍 |
| 42 | 莫扎特《弦乐小夜曲》1–8 小节 + 第 9 小节的 G 和弦 | 祝尼魔乐手 | 上面两排小提琴，下面中提琴、大提琴、低音提琴，一个方块半小节；外排触发距离 3、5 |

时间按农场小路上 100% 速度跑步算：一格 0.1983 秒（实测：速度 5，地板再加 0.1），所以三首的方块速度是 76 / 101 / 151。

每个方块都写明了自己的触发距离（`r=1`、`3`、`5`），不继承全局的：玩家在全局页把触发距离调大，各排也不会听到别排的方块。

曲谱来自 Mutopia Project 的公有领域版本（`arabesque.txt`、`nachtmusik.txt` 文件头写了出处）。

## 重新生成

在 Mac mini 上只带本模组、ConsoleCommands、SaveBackup 启动（不要带改地图的模组，例如 FarmxN）：

```sh
cd ".../Stardew Valley/Contents/MacOS"
./StardewModdingAPI --mods-path Mods-showcase    # Mods-showcase 里放这三个模组（可以是指向 Mods 的软链接）
```

（`./StardewValley` 启动脚本会吞掉所有参数，所以直接调 `StardewModdingAPI`。）然后用调试桥（`docs/DEVELOPMENT.md`）：

```
newgame Maestro Orchestra Music      # 标题画面：新游戏，标准农场，跳过开场
waitworld
<python3 gen.py 输出的每一行>         # 清空农场，摆方块、小路、牌子、箱子
save
```

存档在 `~/.config/StardewValley/Saves/Orchestra_<id>/`。存之前缩放要是 1、HUD 打开（这些选项存在存档里）。

只改了 `gen.py`、想在原来的存档上重摆：载入存档（这一局别做别的测试），跑 `gen.py` 的输出（第一步 `clearfarm` 会清掉
农场上所有东西，再全部摆回来），然后 `save`。
